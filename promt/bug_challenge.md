다음 형식의 JSON으로 bug_challenge 콘텐츠를 생성해줘:

{
"type": "bug_challenge",
"title": "[이모지] [버그 유형, 18자 이내]",
"code": "[3-8줄, 각 줄 40자 이내, \\n으로 줄바꿈]",
"answer": "[80-100자, 문제 설명 + 해결방법]",
"tags": ["[소문자 태그]"]
}

조건:
- 기술 스택: 랜덤으로 결정
- 난이도: 중급
- 초보자가 흔히 하는 실수
- 실행은 되지만 논리적 오류
- title의 이모지는 내용에 어울리게 선택 (🐛, ⚠️, 🔍, 🚨 등)
- 말투: 도전적이고 흥미롭게 ("~해보세요", "~했나요?")
- 목표 학습 시간: 10-15초
