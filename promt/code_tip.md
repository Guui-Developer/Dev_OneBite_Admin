다음 형식의 JSON으로 code_tip 콘텐츠를 생성해줘:

{
"type": "code_tip",
"title": "[이모지] [핵심 키워드, 18자 이내]",
"code": "[1-3줄, 각 줄 40자 이내, \\n으로 줄바꿈]"
"language": "[JavaScript|Python|React 등 기술 스택에 따라 마크다운 스니펫에 맞는 형태로 결정]",
"description": "[40-50자, 한 문장]",
"tags": ["[소문자 태그1]", "[소문자 태그2]"]
}

조건:
- 기술 스택: 랜덤으로 결정
- 난이도: 초급
- 주제: 기술 스택에 따라 랜덤으로 결정
- 실무에서 자주 사용하는 팁
- title의 이모지는 내용에 어울리게 선택 (💡, ✨, 🎯, 🔥 등)
- 말투: 친근하고 실용적 ("~해요", "~이에요")
- 목표 학습 시간: 10-15초
- code는 한 줄에 40자 넘지 않게
