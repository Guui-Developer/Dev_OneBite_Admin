다음 형식의 JSON으로 code_review 콘텐츠를 생성해줘:

{
"type": "code_review",
"title": "[이모지] [개선 포인트, 18자 이내]",
"before": "[3-5줄, 각 줄 40자 이내]",
"after": "[3-5줄, 각 줄 40자 이내]",
"feedback": "> [80-100자, 개선 사항]",
"tags": ["[소문자 태그1]", "[소문자 태그2]"]
}

조건:
- 기술 스택: 랜덤으로 결정
- 난이도: 초급
- 실무에서 자주 보는 패턴
- title의 이모지는 내용에 어울리게 선택 (👨‍💻, ✅, ⚡, 🎨 등)
- 말투: 건설적이고 교육적 ("~하면 더 좋아요", "~로 바꿔보세요")
- 목표 학습 시간: 10-15초
- feedback은 "> "로 시작
- 부정적 표현 지양, 개선점 강조
